> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 조기경보와 치명 핸드오프에 시각 피처를 뺀 상위 피처 3개와 그 1분의 19개 채널 초당 값 전부를 싣는다(스키마 1.4).

**Architecture:** 순수 빌더 `rag_mapping.sensor_block`이 `g.rows`를 변화점 형식 블록으로 만든다. `main.py`의 `attach_handoff`가 `window=(윈도우, 벡터)`를 받아 두 필드를 채우고, 조기경보는 onset 윈도우를, 치명은 `critical_window`가 고른 윈도우를 넘긴다. `build_handoff`는 버전 외에 바뀌지 않는다.

**Tech Stack:** Python 3.11, FastAPI, Pydantic v2, pandas, pytest, ruff

**Spec:** `ml/docs/superpowers/specs/2026-11-06-handoff-v1-4-design.md` (사용자 승인 11-06). 코드 스케치는 7절, 읽기 규칙은 9절, 테스트 목록은 10절에 있다. 이 계획은 스펙을 다시 쓰지 않고 순서와 결정만 적는다.
