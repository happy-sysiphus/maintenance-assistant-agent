## Build & Test Commands
- **Preprocess**: `python .py/preprocess.py` (train, ~7 min) → `python .py/preprocess.py --split test`
- **Train + evaluate**: `python .py/train.py --exclude-non-welding --cv 4` (~10 min; default `--model ensemble` = IsolationForest + LightGBM, the serving model) → `python .py/train.py --evaluate`; IsolationForest alone: `--model iforest` (~1 min)
- **Experiments**: `python .py/experiments.py cache --window 60` → `python .py/experiments.py run <name>` (results in `results/`); paper-protocol comparison: `python .py/paper_task.py cache` → `run` → `summary` (~50 min, `results/B-6/`)
- **Run Server**: `uvicorn main:app --reload` (stream replay: `python .py/replay.py`; state persists in `RSW_STATE_DIR`, default `state/`)
- **Model loop (D-11)**: `python .py/model_loop.py replay --start 2021-08-16` (retrain / shadow comparison / swap over the files of `preprocessed/` in time order; the same command resumes) → `report --out results/D-11/runs/<name>`; one tick: `tick [--server-url http://localhost:8000]`; `status`; `rollback [--by name --reason why]` (a swap is provisional until the next judgement confirms it or takes it back); `feedback pull --api-url http://localhost:9000` (D-12: the operator verdicts of the closed early-warning cases go into `<registry>/feedback.json`; the next training leaves the confirmed spans out of the normal data). New raw files: `python .py/preprocess.py --split append --input-dir <dir>`. Server on the registry: `RSW_MODEL_REGISTRY=models/registry uvicorn main:app` (`POST /model/reload`, `GET /model/loop`)
- **Run Tests**: `pytest` (238 tests, synthetic end-to-end + serving regressions + restart / outbox + C-8 early warning + C-9 defaults + D-11 model loop + D-12 operator verdicts, ~9 min; `pytest tests/test_model_loop.py tests/test_feedback.py` alone: the loop logic and the verdict rule without training, 5 s; never touches the real data folders)
- **Run Single Test**: `pytest tests/test_pipeline.py -k rule`
- **Lint**: `ruff check .` (config in `pyproject.toml`, line length 120)

## Code Style & Architecture
- **Environment**: Python 3.11+, Windows, CPU-only. pandas / scikit-learn / FastAPI + Pydantic v2.
- **Layout**: scripts in `.py/` (`preprocess.py` → `train.py`; `replay.py` stream replay; `model_loop.py` + `model_registry.py` D-11 model loop (registry in `models/registry/`, spec `docs/superpowers/specs/2026-11-11-model-loop-design.md`); `model_feedback.py` D-12 operator verdicts (spec `docs/superpowers/specs/2026-11-12-feedback-labels-design.md`); `rag_mapping.py` handoff; labs `experiments.py`, `paper_task.py`, `physics.py`; later experiments as `results/<task ID>/*.py` next to their JSON), API in root `main.py` (+ `static/trace.html` chart), which imports `train` / `preprocess` so that training and serving share one implementation. Tests in `tests/` (`test_pipeline.py`, `test_rag_mapping.py`, `test_sensor_features.py`, `test_model_loop.py`, `test_feedback.py`). Per-minute sensor document: `.py/sensor_features.py` (schema `docs/sensor_features.schema.json`; not sent - RAG declined it and ML does not push it, history.md 37). Handoffs go to FE's api, which passes only the terminal code to RAG. API examples in `docs/*.example.json`, regenerated by `python docs/make_examples.py` after a model / mapping / schema change. No database.
- **Data constraint**: the provided `train/` / `test/` CSVs are the only data there is — do not plan work that needs outside data.
- **Type Hints**: Explicit type hints for function parameters and return values in `main.py`; the `.py/` scripts follow their existing style.
- **Validation**: Pydantic v2 schemas for all API request/response models. `AnomalyResult` / `RagHandoff` / sensor-features are contracts: add fields, never remove or change meaning (exception: handoff v1.2 removed symptoms / situation ids by the user's decision, history.md 33). ML sends facts (codes, fault class, sensor z), never situation-doc interpretations.
- **Paths**: from `PROJECT_ROOT` (`__file__`), never the cwd. Outputs go to `models/`, `results/`, `eda_out/` (serving state: `state/`), never into `train/`, `test/`, `preprocessed/`.

## Token & Output Optimization Rules
- **Concise Responses**: Skip intros, outros, polite chatter, and conversational filler.
- **Diff-focused Output**: When modifying files, show only the changed code snippet or apply edits directly without reprinting entire unchanged files.
- **Targeted Reading**: Read specific referenced files (`@file`) instead of scanning whole directories unless explicitly instructed.
- **Self-Healing Loop**: Run tests (`pytest`), inspect error logs directly, fix the code, and re-run until passing without long verbal explanations.
