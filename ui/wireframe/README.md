# 와이어프레임

캔버스에서 그린 와이어프레임의 2026-10-02 복사본.

## 폴더

| 경로 | 내용 |
|---|---|
| `screenshots/*.png` | 화면별 그림. 먼저 이걸 본다 |
| `boards/*.dc.html` | 화면별 HTML 원본. 브라우저로 바로 열 수 있다 (정적 목업, 동작 없음) |
| `canvas-notes.md` | 캔버스에 붙어 있던 화면별 설명 메모 (FE 담당이 직접 고쳐 쓴 내용 포함) |
| `canvas.json` | 캔버스 배치 정보 (화면 위치·제목·메모 원본) |

이 HTML은 구현 코드가 아니라 **무엇을 보여줄지 정한 목업**이다. 색·간격·컴포넌트 이름을 그대로 옮길 필요는 없다.
화면 안의 값은 예시이고, `[담당자]`, `[시각]`, `[값]` 같은 대괄호는 아직 정해지지 않은 자리다.

## 현재 흐름 (4단계)

```
① 작업함 ──▶ ② 원인 찾기·조치 ──▶ ③ 정비일지·종료 ──▶ ④ 정비 이력
                │  후보마다 반복:
                │  점검 → 판단 → 실제 수행 조치 → 결과
                ├─ 근거 없음 ──▶ 수동 모드
                ├─ 직접 재야 함 ──▶ 현장 확인 체크시트 (측정 후 복귀)
                └─ 혼자 해결 못 함 ──▶ 인계서
```

## 화면 목록

### 핵심 흐름

| 파일 | 화면 | 역할 |
|---|---|---|
| `Main` | ① 작업함 | 처리할 케이스 목록. 경보·설비·코드·추정 유형·진행 상태·발생 시각. 반복 코드는 한 줄로 묶음 |
| `Resolve` | ② 원인 찾기·조치 (통합) | 핵심 화면. 맨 위 "무슨 일이 났나"(코드·작은 그래프·달랐던 신호), 후보 카드(점검 → 판단 → 조치 → 결과), 오른쪽 근거·AI 요약·루프 기록 |
| `Resolve1` | ② 비교 1안 | 끝난 단계는 한 줄로 접히고 지금 할 일만 크게. 결과 칸은 조치 저장 후 열림 (Claude 추천) |
| `Resolve2` | ② 비교 2안 | 왼쪽은 후보·점검·판단, "맞음"을 누르면 오른쪽에 조치 패널 |
| `Logbook` | ③ 정비일지·종료 | 앞 단계 기록으로 채운 일지 초안. "일지 승인"과 "해결 종료"는 다른 버튼 |
| `History` | ④ 정비 이력 | 닫힌 케이스 읽기 전용 |

②의 화면 방식(`Resolve` / 1안 / 2안)은 팀 확정 전이다. 세 화면의 내용은 같고 보여주는 방식만 다르다.

### 옆길

| 파일 | 화면 | 언제 |
|---|---|---|
| `Manual` | 수동 모드 | 매뉴얼 근거가 없을 때. 점검 순서를 지어내지 않고 AI 요약도 숨김 |
| `FieldCheck` | 현장 확인 체크시트 | 센서로 알 수 없어 사람이 직접 재야 할 때 |
| `Handover` | 인계서 | 담당자가 해결 못 할 때 전문가에게 넘김 |

### 부록

| 파일 | 화면 | 역할 |
|---|---|---|
| `Equipment` | 설비 상태 | "지금 이 설비를 판단할 수 있나" — 기준 수집 중, 판단 보류 |
| `Replay` | 재생 콘솔 | 공개 CSV를 실시간처럼 재생 (데모용). 레포에는 CLI만 있고 API는 없음 |
| `States` | 공통 상태 | 로딩·실패·결측·근거 없음 등 모든 화면이 같이 쓰는 상태 (FE 개발용) |

### 보관 (지금 흐름에서는 안 씀 · 회의 비교용)

| 파일 | 옛 화면 | 왜 뺐나 |
|---|---|---|
| `Triage` | ② 상황 파악 | 사람의 1차 판단(실제 이상 / 오탐 / 모니터링)을 뺌. LLM 결과가 케이스 트리거 |
| `Guide` | ③ 원인 후보·점검 | 통합 화면의 후보 카드로 옮김. "원인으로 확정" 버튼 대신 후보마다 판단 |
| `Action` | ④ 조치 기록 | 통합 화면 후보 카드 안 "실제 수행 조치" 칸으로 |
| `Verify` | ⑤ 재검증 | 공개 데이터에 조치 후 구간이 없어 전부 시뮬레이션이었음. 결과 칸 + 자동 표시 한 줄로 대체 |

## 화면 공통 규칙

- 값마다 출처: [데이터] 공개 CSV 원본 · [모델] ML이 계산 · [매뉴얼] 문서 검색 결과 · [사람] 사용자 입력 · [AI] LLM 생성 · [시뮬레이션] 데모용 가상 값.
- 색은 경보(빨강·주황)에만 쓰고 나머지는 차분하게.
- 컨트롤러 코드(E012), 데이터셋 클래스(E01), 매뉴얼 오류 번호(Festo 12)는 서로 다른 칸에.
- AI 권고는 초안으로만 불러오고, 정비일지에는 사람이 실제로 한 일만 들어간다.
- 근거가 없으면 수동 모드로 바꾸고 AI 요약을 숨긴다.
- 인계 버튼은 어느 단계에서든 누를 수 있다.
