제조업을 처음 보는 FE 담당자를 위한 한 장 요약. 화면에 나오는 단어가 현장에서 무엇을 뜻하는지, FE에서 무엇을 조심해야 하는지 적었습니다.

로봇 점용접 건 (개념도)

실제 형상 아님

점용접(RSW): 철판 두 장을 전극 두 개로 꽉 누른 채 전류를 흘려 한 점씩 붙이는 방식. 차체 한 대에 수천 점을 로봇이 찍습니다. 우리 데이터의 건은 공기압 실린더를 제어기가 정밀하게 조절하는 '서보 공압식'입니다 (논문 기준, 제조사·모델은 비공개).

1주 실린더 — 전극을 눌러 힘을 만듦. c2 전극 힘, c3 전극 위치, c4 힘 형성(거의 0/1 값)
2보정(밸런스) 실린더 — 건이 판 양쪽에 고르게 닿도록 균형을 잡음. c5 밸런스 압력, 목표값 c13. 이 압력이 제때 안 오르면 E01 유형 고장
3제어기 — 목표값(설정값 c13~c18)을 내리고, 1초마다 상태 코드(error 컬럼)를 남김
4전극 캡 — 판에 닿는 끝. 닳으면 깎거나(드레싱) 교체. 이때는 용접을 안 해서 c16 ≤ 0 (비용접 구간)
5철판 두 장 — 판 두께 설정값 c16. 용접 횟수는 누적 카운터 c11
공개 데이터에 있는 것
  • 고장 7일 전 ~ 고장 10분 후 신호 (1초 간격)
  • 고장 순간의 종료 코드와 시각
  • 결측·비용접 구간
없는 것 → 화면에서 추정 금지
  • 실제 정비 조치 기록, 조치 후 신호
  • 센서 단위, 장비 모델, 코드 의미 사전
  • 설비별 과거 이력
설정값 vs 실제값

설정값(c13~c18)은 제어기가 목표로 준 값, 실제값(c2~c6)은 센서가 잰 값. 둘이 크게 벌어지면 이상입니다.

FE: 설정값은 계단선, 스케일이 다르면 따로 그리기
컨트롤러 코드 E012

제어기가 남기는 상태 코드 11종. 고장 순간에 뜨는 4개(E012·E016·E028·E029)를 '종료 코드'라 부릅니다.

FE: 의미 사전이 없으면 코드 원문만 표시
데이터셋 클래스 E01~E04

논문이 파일에 붙인 고장 유형. 컨트롤러 코드와 체계가 다릅니다. 화면에서는 '클래스 힌트(추정)'로만 씁니다.

FE: E01과 E012를 같은 칸에 넣지 않기
매뉴얼 오류 번호 Festo 12

다른 회사 제어기의 번호 체계. 이름이 비슷해 보여도 E012와 같은 코드라는 근거가 없습니다.

FE: 근거 카드에 "별도 코드 체계" 표시
비용접 · 캡 드레싱

전극 끝을 깎거나 바꾸는 시간. 센서값이 멈춰 보이므로 이 구간의 이상 점수는 믿지 않습니다.

FE: 빗금 띠 + "판단 보류"
워밍업 (기준 수집)

설비마다 '평소 값'을 6시간 모아 기준을 만듭니다. 정비 후에도 다시 모읍니다. 그동안은 판정이 약합니다.

FE: 진행률 + "판정 대기"
이상 점수 · 임계값

평소와 얼마나 다른지 나타내는 점수와 그 기준선. 고장 확률이 아닙니다.

FE: %로 바꾸지 않기
결측

통신이 끊겨 그 초의 기록 자체가 없는 것. 값 0과 다릅니다.

FE: 선 끊기, 보간·0 채우기 금지
케이스 · 후보 루프

케이스는 고장 사건 하나. 그 안에서 원인 후보를 하나씩 '점검 → 판단 → 조치 → 결과'로 확인하고, 아니면 다음 후보로 넘어갑니다.

FE: 후보마다 판단 · 조치 · 결과 따로 저장
근거 적용 등급

이 매뉴얼이 우리 장비에 얼마나 맞는지. 직접 적용 / 구조 참고 / 비교만 / 미확인 / 제외.

FE: 등급 배지 + 이유 한 줄
결과 확인

조치 뒤 해결됨 / 해결 안 됨은 사람이 고름. 옆에 "종료 코드 재발 없음"을 시스템이 자동 표시 (재검증 화면은 뺌).
